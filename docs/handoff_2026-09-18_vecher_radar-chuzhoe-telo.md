### Как работать — выучено сегодня

- **git до GitHub через en0.** Маршрут по умолчанию — VPN (`utun8`), push висит по 75 с.
  git не умеет привязываться к интерфейсу, поэтому локальный CONNECT-прокси привязывает
  сокет к en0 (`IP_BOUND_IF`): `python3 en0_proxy.py 18080 &`, затем
  `git -c http.proxy=http://127.0.0.1:18080 push origin main`. Скрипт — в скретчпаде
  сессии; рецепт — в памяти `oiltech-vpn-path-blackhole-0720`. SSH к GitHub через en0 не
  вариант: порт 22 закрыт, на 443 у Mac нет ключа на GitHub.
- **Починка тел**: `docker compose exec -T app python -m oiltech_digest.cli repair-article-bodies`
  с `--source-id N --days 60`, `--statuses too_short,mismatch` или `--ids …`; по умолчанию
  сухой прогон, `--apply` пишет и ставит пересчёт ИИ пакетами по 25. Долгий прогон —
  `docker exec -d … > /tmp/x.json`; пока он идёт, `app` **не пересоздавать**.
- **Мерка «заголовок в начале тела» годится только для старых тел**: новое извлечение
  берёт тело без шапки — повторно гонять починку по этой мерке нельзя (ложные «чужие»).
