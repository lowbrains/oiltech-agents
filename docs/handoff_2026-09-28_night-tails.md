## Правило тестов (обязательно)

Одна локальная база Postgres в colima на всех. Одновременные прогоны её ломали. Любой pytest —
только под общим замком, одной командой:

```sh
L=/private/tmp/oiltech-pytest.lock; until mkdir "$L" 2>/dev/null; do find "$L" -maxdepth 0 -mmin +20 -exec rm -rf {} \; ; sleep 15; done; echo "$(date) <кто>" > "$L/owner"; /Users/apple/Desktop/oiltech-digest/.venv/bin/python -m pytest <что> -q -p no:cacheprovider; code=$?; rm -rf "$L"; echo "pytest exit=$code"
```

- Базы не создавать, контейнеры не поднимать, colima не трогать.
- Плавающий `test_background_jobs`: часы colima откатываются примерно на 1 с, и задача с
  `run_after = now()` на миг оказывается «в будущем». При сбое перезапустить отдельно.
