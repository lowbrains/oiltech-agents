# Агент источников — коротко

## Что это

Агент ищет новые сайты для мониторинга — разделы новостей, пресс-центры компаний, отраслевые издания — по темам, где платформе не хватает материалов. Найденные сайты он проверяет и показывает как кандидатов с оценкой. Сам в ленту ничего не добавляет: решает человек, а агент учится на этих решениях. Сейчас агент запускается только кнопкой и работает без ИИ-модели — по шаблонам и правилам, поэтому его оценки приблизительные.

## Схема работы

**Темы → Поиск → Проверка → Кандидат → Решение человека → Источник → Память → следующий поиск**

1. **Темы.** Агент берёт темы (теги платформы), по которым за 30 дней собрано меньше 10 подходящих материалов.
2. **Поиск.** Составляет запросы на русском и английском, ищет сайты в интернете, отбрасывает уже известные и запрещённые.
3. **Проверка.** Открывает сайт, берёт до 5 свежих статей и оценивает тему, качество и регулярность; в ленту эти статьи не попадают.
4. **Кандидат.** Добавляет сайт в список с вердиктом: «добавить», «проверить ещё», «не добавлять» или «нужен человек».
5. **Решение человека:** «Одобрить», «Шум», «Дубликат» или «Ещё проверить».
6. **Источник.** Одобренный сайт становится источником агента — выключенным, с одним пробным сбором статей. В основную платформу его переносят отдельно.
7. **Память.** Агент повышает или понижает баллы сайта, темы и запроса и учитывает их в следующем поиске. Это таблица баллов, а не переобучение нейросети.

## Что на экране

| Элемент | Что значит |
|---|---|
| Запустить цикл (то же, что «Запустить loop») | Запуск агента: до 3 кругов поиска и проверки подряд |
| Пробный запуск | То же без сохранения: что агент нашёл бы |
| Построить план | Какие темы агент будет искать; ничего не запускает |
| Поставить в очередь | Один проход по плану в фоне |
| Кандидаты | Все найденные сайты и решения по ним |
| Состояние агента | Готовность к работе; «ограниченный режим» — есть замечания, но работать можно |
| «Суточный лимит loop_runs исчерпан: 9/6» | 9 запусков за сутки при лимите 6; считается и нажатие, остановленное лимитом |
| «Последний запуск #156 … daily_loop_budget_reached» | Запуск сразу остановлен суточным лимитом: 0 кругов («итераций»), 0 кандидатов |
| Что делать сейчас | Сколько кандидатов ждут решения (экран считает не больше 8) |
| Вывод агента | Что получилось в последнем запуске и что агент поменяет в следующем |
| Быстрый seed-URL | Дать агенту адрес сайта вручную. «Проверить доступность» — открывается ли сайт, «Пробный парсинг» — удаётся ли взять статьи |
| Что агент сделал / рекомендует / запомнил | Журнал действий; темы для следующего поиска; баллы сайтов и запросов |
| Где нужен человек | Кандидаты на решение: «Итог» — оценка 0–100, «Решение» — вердикт агента, «Качество» — сильный / перспективный / сомнительный / шумный |

## Что нужно от вас

1. Разбирать кандидатов в блоке «Где нужен человек»: «Одобрить» — сайт полезен, «Шум» — не по теме, «Дубликат» — повторяет имеющийся источник. На этих решениях агент учится.
2. Перед одобрением смотреть статьи кандидата: без ИИ-модели агент считает подходящими почти все статьи, поэтому вердикты завышены.
3. Давать агенту известные вам хорошие источники через «Быстрый seed-URL» — адрес раздела новостей или пресс-центра, а не отдельной статьи.
